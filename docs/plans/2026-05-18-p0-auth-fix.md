## Task 1: Add auth middleware
**Time**: 5min
**TDD**: Write test first → test fails → implement → test passes

### Test
```python
# tests/test_auth.py
def test_local_request_no_token_ok():
    """Request from 127.0.0.1 should pass without token"""
    # GET /api/devices from 127.0.0.1 → 200

def test_remote_request_no_token_fail():
    """Request from non-local IP without token → 401"""
    # GET /api/devices with remote IP → 401

def test_remote_request_valid_token():
    """Request from remote IP with valid token → 200"""
    # GET /api/devices with header Authorization: Bearer <token> → 200

def test_remote_request_invalid_token():
    """Request from remote IP with wrong token → 401"""
    # GET /api/devices with wrong token → 401
```

### Implementation
- Add `before_request` hook in app_local.py
- Check `request.remote_addr`: 127.0.0.1/::1 → pass
- Non-local → check `Authorization: Bearer <token>` header
- Token from env var `NETOPS_API_TOKEN`, auto-generate if not set, print on startup
- Exempt: `@app.route('/')` (index page)

### Commit
`feat: add API token auth for remote requests`
